Расшифровывайте аудио и видео в текст. На своём компьютере.

S2T Local распознаёт речь в записях встреч и интервью, разделяет реплики по спикерам и сохраняет результат в TXT. Аудиофайлы не отправляются в облако для распознавания.

Windows 10/11 x64 · Portable ZIP · без установки Python · при первом запуске потребуется загрузить движок (~1,4 ГБ).

Для записей, с которыми нужно работать

Разделение спикеров

Реплики группируются по говорящим. Метки спикеров можно переименовывать; автоматическое разделение требует проверки.

Очередь записей

Добавляйте аудио- и видеофайлы, отслеживайте прогресс и состояние обработки.

Результат в TXT

Читайте транскрипт в браузере, копируйте текст или скачивайте файл.

Как работает S2T Local

  1. Скачайте ZIP с официального GitHub Releases и запустите S2T-Local.exe.
  2. Установите движок при первом запуске: приложение загрузит Faster-Whisper-XXL по вашему запросу.
  3. Добавьте запись, выберите «Точно» (medium) либо «Быстро» (small), а также число спикеров.
  4. Получите транскрипт в локальном веб-интерфейсе и скачайте TXT.

Веб-интерфейс открывается на 127.0.0.1:8765, но обработка выполняется локально в приложении Windows. Это не онлайн-сервис.

Типичные задачи

Расшифровка интервью

Работа с репликами интервьюера и респондентов, анализ длинных разговоров.

Расшифровка совещаний

Создание текстовой расшифровки рабочей встречи для последующего протоколирования.

Локальная работа

Запись и транскрипт остаются на вашем ПК. При добровольной отправке отзыва действуют отдельные условия приватности.

Перед скачиванием: три важных момента

Подойдёт ли мой компьютер?

Эта сборка для Windows 10/11 x64. Проверьте: «Параметры → Система → О системе → Тип системы». Нужна 64-разрядная система на процессоре x64. Поддержка Windows ARM64 не заявлена.

Какой файл запускать?

Скачайте S2T-Local-0.1.3-windows-x64.zip (не «Source code»), распакуйте архив полностью и откройте S2T-Local.exe. Второй файл, s2t-transcriber.exe, — служебный модуль: не запускайте и не удаляйте его.

Нужен ли файл SHA-256?

Нет, для обычного запуска не нужен. Файл .sha256.txt нужен только для добровольной проверки совпадения скачанного архива с опубликованным. Это не цифровая подпись издателя.

Системные требования и ограничения

Рекомендуется совместимая видеокарта NVIDIA; возможен CPU-режим. Скорость зависит от оборудования, длины записи и выбранной модели. Python отдельно устанавливать не нужно. После первого запуска потребуется отдельная загрузка движка Faster-Whisper-XXL (~1,4 ГБ).

Программа находится в раннем доступе. У Windows-EXE пока нет сертификата подписи: SmartScreen может показать предупреждение. Скачивайте только из официального релиза. Как по желанию проверить SHA-256.

Cloud Boost в 0.1.3 — демонстрационный режим. Настоящая облачная транскрибация и оплата отсутствуют. Отдельная проверка этой версии на совершенно новой Windows-системе ещё не выполнена.

Вопросы и ответы

Нужно ли загружать запись на сервер?

Нет. Для распознавания приложение обрабатывает записи локально. Кнопки Cloud Boost и обратной связи описаны отдельно в политике приватности.

Можно ли распознать часовой файл?

Да, приложение предназначено в том числе для длинных записей. Скорость и качество зависят от компьютера, записи и выбранного режима.

Можно ли автоматически получить протокол встречи?

Сейчас S2T Local создаёт транскрипт в TXT. Генерация протокола и списка задач не входит в версию 0.1.3.

Сколько стоит?

Версия Early Access 0.1.3 доступна бесплатно. Платной транскрибации в приложении сейчас нет.
