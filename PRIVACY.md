# Privacy — S2T Local Early Access

## Локальная обработка

По умолчанию S2T Local работает локально. Аудио, видео, транскрипты и история задач хранятся на компьютере пользователя.

S2T Local не включает фоновую продуктовую аналитику.

## Сигнал интереса к Cloud Boost

Cloud Boost пока не выполняет облачную обработку.

Если пользователь явно нажимает кнопку «Хочу в облако» и подтверждает отправку анонимного сигнала, S2T Local отправляет в PostHog событие `cloud_boost_interest_clicked`.

Передаются:

- случайный идентификатор установки;
- версия S2T Local;
- выбранный режим распознавания;
- состояние задачи;
- диапазон длительности аудио;
- диапазон ожидаемого локального времени обработки.

Не передаются:

- аудио или видео;
- текст транскрипта;
- имя файла;
- локальный путь;
- идентификатор задачи.

Для этого события отключено создание PostHog person profile и GeoIP enrichment. В PostHog также включена настройка Discard client IP data.

Случайный идентификатор установки создаётся локально только после первого подтверждённого сигнала интереса к Cloud Boost.
