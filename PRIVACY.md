# Privacy — S2T Local Early Access

## Локальная обработка

По умолчанию S2T Local работает локально. Аудио, видео, транскрипты и история задач хранятся на компьютере пользователя.

S2T Local не включает фоновую продуктовую аналитику.

## Сигнал интереса к Cloud Boost

Cloud Boost пока не выполняет облачную обработку.

Если пользователь явно нажимает кнопку «Хочу в облако» и подтверждает отправку анонимного сигнала, S2T Local отправляет в PostHog событие `cloud_boost_interest_clicked`.

Передаются:

- случайный идентификатор установки;
- версия S2T Local;
- выбранный режим распознавания;
- состояние задачи;
- диапазон длительности аудио;
- диапазон ожидаемого локального времени обработки.

Не передаются:

- аудио или видео;
- текст транскрипта;
- имя файла;
- локальный путь;
- идентификатор задачи.

Для этого события отключено создание PostHog person profile и GeoIP enrichment. В PostHog также включена настройка Discard client IP data.

Случайный идентификатор установки создаётся локально только после первого подтверждённого сигнала интереса к Cloud Boost.

## Обратная связь (начиная с версии 0.1.3)

Кнопка «Обратная связь» позволяет добровольно отправить текстовое сообщение
разработчику. Перед отправкой требуется отдельное явное согласие.

В PostHog (США) отправляются только:

- выбранная категория сообщения;
- введённый пользователем текст (10–1500 символов);
- версия приложения и время события;
- случайный одноразовый идентификатор события.

Автоматически не прикрепляются аудио, видео, транскрипты, локальные пути,
имена файлов и история задач. Для события отключены создание профиля и
обогащение GeoIP. Не включайте в текст персональные данные, пароли, секреты
или содержимое конфиденциальных встреч. Если передавать отзыв не хотите,
просто закройте форму — ничего не отправится.

При ошибке связи приложение сообщает о неуспешной отправке, сохраняя текст
в открытой форме для исправления или повторной попытки; локальное сохранение
отзывов не выполняется. В версии v0.1.2 этой функции не было; она появилась в v0.1.3.

## Cloud Boost — симуляция без расходов (начиная с версии 0.1.3)

Тестовый режим Cloud Boost имитирует очередь, состояние, ошибки и виртуальный
баланс минут в памяти приложения. Он не открывает соединение с облачным
провайдером, не загружает аудио и не проводит распознавание. Виртуальная
стоимость всегда равна 0 ₽, а баланс сбрасывается при перезапуске.

## Контакт
