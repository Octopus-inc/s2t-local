# S2T Local 0.1.2 — Early Access

Главное изменение версии 0.1.2 — автоматическая установка Faster-Whisper-XXL при первом запуске.

## Что нового

- Кнопка **«Установить движок»** прямо в S2T Local.
- Faster-Whisper-XXL скачивается напрямую из официального релиза Purfview.
- Загрузка примерно 1,4 ГБ поддерживает продолжение после прерывания.
- Загруженный архив проверяется по ожидаемому размеру и SHA-256.
- Для распаковки временно скачивается официальный `7zr.exe` от 7-Zip; его SHA-256 также проверяется.
- Движок устанавливается в локальные данные S2T Local и сохраняется при замене или обновлении portable-папки приложения.
- Ручная установка Faster-Whisper-XXL остаётся доступна как fallback.

- Windows ZIP SHA-256: `b6cb6a49ff2460143fc650b608a6b1f658d930b20e304dcbfff1084f157a1adc`
- Faster-Whisper-XXL archive SHA-256: `237dee23939cdabfc96ef859fc5e584b842c3a5557e0d2ca744e1f87c14c5844`

Перед публикацией этот кандидат прошёл:
- независимый GitHub Actions source-check;
- Windows portable build;
- packaged health/API smoke test;
- реальную first-run установку Faster-Whisper-XXL;
- независимую проверку SHA-256 скачанного XXL-архива;
- проверку повторного запуска;
- проверку сохранения установленного движка после полной замены portable-папки приложения.

## Важно

- S2T Local не включает Faster-Whisper-XXL в ZIP и не перераспространяет его бинарники.
- Windows-бинарник S2T Local пока не подписан сертификатом, поэтому SmartScreen может показать предупреждение.
- Cloud Boost пока не выполняет облачную обработку.
