# S2T Local

Бесплатный Early Access локальной транскрибации аудио и видео на Windows с разделением по спикерам.

## Что это

S2T Local запускает распознавание на вашем компьютере и открывает локальный Web UI на `127.0.0.1`.

Основные возможности:

- очередь нескольких файлов;
- режимы «Точно» и «Быстро»;
- разделение по спикерам;
- автоматический или ручной диапазон количества спикеров;
- мониторинг CPU, GPU и VRAM;
- прогресс и оценка времени;
- пауза, остановка и повторный запуск;
- локальная история;
- переименование и фильтрация спикеров;
- копирование и скачивание TXT.

## Скачать

Используйте последний GitHub Release этого репозитория.

Текущая версия Early Access: **0.1.1**.

Перед распаковкой при желании проверьте SHA-256 по приложенному файлу `.sha256.txt`.

## Установка

1. Скачайте `S2T-Local-0.1.1-windows-x64.zip`.
2. Распакуйте архив в обычную папку, например `C:\Apps\S2T Local`.
3. Скачайте Faster-Whisper-XXL из официальных Releases проекта Purfview:
   https://github.com/Purfview/whisper-standalone-win/releases
4. Распакуйте Faster-Whisper-XXL внутрь папки `engine` рядом с `S2T-Local.exe`.
5. Запустите `S2T-Local.exe`.

Python устанавливать не нужно.

## Локальные данные

Задачи, исходные файлы и результаты хранятся локально:

`%USERPROFILE%\.s2t-local`

По умолчанию интерфейс доступен только на:

`http://127.0.0.1:8765`

## Cloud Boost

Облачная обработка пока не запущена.

Когда локальная обработка занимает заметное время, S2T Local может показать кнопку «Хочу в облако». После явного подтверждения приложение отправляет только анонимный сигнал интереса, чтобы оценить спрос на будущую функцию.

Аудио и текст при этом не загружаются. Подробности: [PRIVACY.md](PRIVACY.md).

## Известные ограничения

- Faster-Whisper-XXL устанавливается отдельно;
- Windows-бинарник пока не подписан сертификатом, поэтому SmartScreen может показать предупреждение;
- Cloud Boost пока не выполняет облачную обработку;
- это Early Access: совместимость с разным железом ещё расширяется.
