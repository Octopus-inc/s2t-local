# S2T Local

Бесплатный Early Access локальной транскрибации аудио и видео на Windows с разделением по спикерам.

## Что это

S2T Local запускает распознавание на вашем компьютере и открывает локальный Web UI на `127.0.0.1`.

Основные возможности:

- очередь нескольких файлов;
- режимы «Точно» и «Быстро»;
- разделение по спикерам;
- автоматический или ручной диапазон количества спикеров;
- мониторинг CPU, GPU и VRAM;
- прогресс и оценка времени;
- пауза, остановка и повторный запуск;
- локальная история;
- переименование и фильтрация спикеров;
- копирование и скачивание TXT.

## Установка — без технической подготовки

1. На [странице релиза 0.1.3](https://github.com/Octopus-inc/s2t-local/releases/tag/v0.1.3) скачайте **`S2T-Local-0.1.3-windows-x64.zip`**. Файлы **Source code (zip/tar.gz)** не нужны для установки. Файл **`.sha256.txt`** тоже скачивать необязательно.
2. Распакуйте ZIP полностью в обычную папку, например `C:\Apps\S2T Local`. Не запускайте EXE из окна архива.
3. Запустите **`S2T-Local.exe`** (с прописными буквами и дефисом). Это главное приложение, которое открывает локальный веб-интерфейс.
4. Рядом лежит **`s2t-transcriber.exe`** — вспомогательный модуль распознавания, запускаемый основным приложением. **Самостоятельно открывать его не нужно, но удалять или перемещать отдельно нельзя.** Храните оба EXE в распакованной папке.
5. При первом запуске нажмите **«Установить движок»** — S2T Local скачает Faster-Whisper-XXL из официального релиза Purfview, проверит размер и SHA-256 и установит движок в локальные данные пользователя. Эта загрузка составляет около 1,4 ГБ.

**Совместимость:** сборка `windows-x64` предназначена для **Windows 10/11 x64** (64-разрядная система на процессоре x64, обычно Intel/AMD). Проверьте: **Пуск → Параметры → Система → О системе → Тип системы**. Для Windows ARM64 эта версия не заявлена как поддерживаемая; слово `x64` не означает требования к видеокарте. Совместимость и скорость на конкретном ПК зависят от железа.

### Нужно ли проверять SHA-256?

**Для обычного запуска — нет.** `S2T-Local-0.1.3-windows-x64.zip.sha256.txt` — необязательный контрольный файл, позволяющий сверить скачанный ZIP с опубликованным. Если хотите проверить:

1. Скачайте ZIP и одноимённый `.sha256.txt` из официального релиза.
2. В PowerShell из папки со скачанным ZIP выполните `Get-FileHash -Algorithm SHA256 .\S2T-Local-0.1.3-windows-x64.zip`.
3. Сравните выведенный хэш с первой строкой `.sha256.txt` или хэшем выше в разделе «Скачать». Они должны совпасть **точно**. Если отличаются — не запускайте архив, загрузите его заново из официального релиза.

SHA-256 проверяет совпадение файлов, но **не заменяет цифровую подпись издателя**. Текущая версия EXE не подписана и может вызывать предупреждение SmartScreen.

Ручная установка Faster-Whisper-XXL из официальных Releases Purfview остаётся доступна как fallback:
https://github.com/Purfview/whisper-standalone-win/releases

Python устанавливать не нужно.

## Локальные данные

Задачи, исходные файлы и результаты хранятся локально:

`%USERPROFILE%\.s2t-local`

По умолчанию интерфейс доступен только на:

`http://127.0.0.1:8765`

## Обратная связь (в 0.1.3)

Кнопка «💬 Обратная связь» принимает добровольное предложение, описание ошибки или замечание по интерфейсу. Текст передаётся в PostHog (США) только после явного согласия. Аудио, история и транскрипты автоматически не передаются. Подробнее: [PRIVACY.md](PRIVACY.md).

## О программе (с 0.1.3)

Кнопка «ℹ️ О программе» показывает версию запущенного приложения, состояние движка Faster-Whisper-XXL и ссылки на приватность и обновления.

## Cloud Boost

Реальная облачная обработка пока не запущена. В 0.1.3 доступно **🧪 Cloud Boost: демо**: локальная имитация очереди и виртуальных минут, без передачи аудио и оплаты.

Когда локальная обработка занимает заметное время, S2T Local может показать кнопку «Хочу в облако». После явного подтверждения приложение отправляет только анонимный сигнал интереса, чтобы оценить спрос на будущую функцию.

Аудио и текст при этом не загружаются. Подробности: [PRIVACY.md](PRIVACY.md).

## Известные ограничения

- при первой установке Faster-Whisper-XXL потребуется загрузка примерно 1,4 ГБ;
- Windows-бинарник пока не подписан сертификатом, поэтому SmartScreen может показать предупреждение;
- Cloud Boost пока не выполняет облачную обработку;
- это Early Access: совместимость с разным железом ещё расширяется;
- полный отдельный тест v0.1.3 на новой чистой Windows-системе не проводился. Пакет проверен на рабочем ПК и в изолированном локальном профиле.
